# 任务报告与截图回放测试版

基线：上游与 fork 的 main 均为 `2c4563bc`（0.1.37），在 `codex/task-report-replay` 实现。
现有 `codex/performance-cost` 分支及其经验文档保持原状；此次复用了其中“指标范围”和“PR 落地判定”的检查结论。

## 阶段与验收

1. 记录：保存实际执行的屏幕动作前后截图及归一化标记，不改变模型上下文；支持单步、批次与脚本；受保护页面不截，记录失败不影响任务。
   - 验收：点击坐标/元素编号、滑动方向、被拒动作、缺图、无视觉模型、旧记录兼容的单测。
2. 界面：沿用 Mika 主题的任务卡片、报告入口、完整 Markdown 报告、关键截图跳转与只读回放。
   - 验收：成功/失败/取消状态真实显示；前帧标记、后帧清除；播放/暂停、1×/2×、逐步与拖动定位；缺图/记录清理说明；返回与重建状态。
3. 发布：全部单测、CLI 与资源检查、Android 构建；发布 fork 预发布版本与 APK、校验和。
   - 包名使用 `com.wangzan101.mika.preview`，名称 Mika Preview，perf 构建签名，避免覆盖正式版。
   - 真实手机的完整模型操作与视觉验收由用户安装后完成；未执行的设备检查不得称为通过。

## 数据与边界

- 截图序列回看不是连续录屏，也不会重新执行动作。
- 报告使用已保存的任务目标、结局、原始回答与截图，不额外调用模型，不编造通用任务字段。
- 点击/滑动坐标遵循现有工具的 0–999 坐标系。语义滚动只显示方向示意，不能当作实际触点。
- 旧记录只有截图时不推测精确动作位置；前后缺图明确显示缺失，不用另一帧冒充。
- 沿用最近 30 次运行的本地保留策略；截图可能包含任务页面内容，报告/回放不上传。
