## 从导出复算

逐组运行仓库的 `eval/usage_compare.py`。例如以下仅示意 A1、A3 通过，**不是实测结果**；应将 `--before` 换成该组所有尝试，`--verified` 只列实际人工通过者，零成功时省略此参数。B、C 同样各算一次。单价单位元/百万 token，命令的顺序是未命中、命中、输出。

```sh
python3 eval/usage_compare.py --before A/*.ndjson --verified A/1.ndjson A/3.ndjson --uniform-prices 2 0.04 8
```

使用整次 `model_calls`：命中率 = 全组命中 / 全组输入；单位成功成本 = 所有尝试费用 / 人工成功数（零成功时留空）。用量缺报、导出不完整或实际混用不同价目时不填确定费用，不删除该次尝试。B、C 按每个导出筛选 `type=prefix_break`，登记 `step/reason/suffixTokens/taskMemoryTokens`；无事件写 0，A 无此遥测写“不适用”。`suffixTokens` 是变化块至请求末尾的估计，不是服务商未命中；`model_reply.taskMemoryTokens` 也记录无打断时的事实块大小。可用如下命令查看单次变化：

```sh
python3 -c 'import json,sys; print(*[(e["step"],e["reason"],e["suffixTokens"],e["taskMemoryTokens"]) for line in open(sys.argv[1]) if (e:=json.loads(line))["type"]=="prefix_break"],sep="\n")' B/1.ndjson
```
